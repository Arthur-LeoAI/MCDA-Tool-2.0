# 0007 结论文字由确定的模板生成，不调用大语言模型

- 状态：提议，待审阅
- 日期：2026-10-23

## 背景

引导模式要给出通俗的结论，例如"推荐 C，因为……；在 82% 的情况下排第一"。可以用大语言模型生成文字，也可以用固定的模板生成。

## 决定

- 后端计算**结构化的结论要点**：第一名、第二名、分差、贡献最大的准则、相对第二名的优势和劣势、可靠程度、被排除的方案、数据方面的提醒。
- 前端按语言用固定模板把要点写成文字。
- MVP 不调用任何大语言模型。

## 理由

- **可复现**：同样的项目永远得到同样的文字，可以写进报告，也可以被审查。
- **准确**：文字里的每个数字都直接来自计算结果，不会出现模型编造的内容。
- **隐私和成本**：用户的业务数据不会发送给第三方服务，也没有调用费用（ADR 0003）。
- **多语言**：只需要翻译模板。

## 后果

- 文字比较程式化。可以通过多准备几种句式（例如按可靠程度、优势是否集中来区分）改善。
- 以后如果要加入大语言模型（例如"帮我解释一下这个结果"），需要单独写 ADR，说明数据怎么处理、怎么核对模型的输出，并作为可选功能。
