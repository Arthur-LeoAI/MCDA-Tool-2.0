# 0007 Conclusion texts are generated from deterministic templates, without calling a large language model

- Status: Accepted
- Date: 2026-10-23

## Context

Guided mode needs to give plain-language conclusions, for example "C is recommended because ...; it ranks first in 82% of cases". The text could be generated by a large language model or from fixed templates.

## Decision

- The backend calculates **structured conclusion points**: first place, second place, score gap, the criteria with the largest contribution, strengths and weaknesses relative to second place, reliability, excluded alternatives, and data warnings.
- The frontend turns the points into text using fixed templates per language.
- The MVP does not call any large language model.

## Rationale

- **Reproducible**: the same project always produces the same text, which can be put into reports and can be reviewed.
- **Accurate**: every number in the text comes directly from the calculation results; there is no content made up by a model.
- **Privacy and cost**: users' business data is not sent to third-party services, and there are no usage fees (ADR 0003).
- **Multilingual**: only the templates need to be translated.

## Consequences

- The text is fairly formulaic. This can be improved by preparing more sentence variants (for example, distinguished by reliability or by whether the strengths are concentrated).
- If a large language model is added later (for example "explain this result to me"), a separate ADR is required that describes how data is handled and how the model output is checked, and it must be an optional feature.
